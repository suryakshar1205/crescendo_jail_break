Crescendo PRD Defense — System Architecture Guide

Full-Stack Multi-Turn Jailbreak Interception Framework

1. Four-Tier Full-Stack Architecture

The system is an integrated full-stack defense framework operating in real-time:

TIER 1
Web Research Testbench
Real-time telemetry, interactive Risk Journey stepper, Security Turn Cards, Trajectory Canvas, and 1-click audit reports.
TIER 2
REST API Gateway
Session state isolation, conversation history buffering, latency profiling, and dynamic preset scenario serving.
TIER 3
Stateful PRD Engine
Sub-25ms FAISS vector similarity, 4-signal fusion (H, E, S, B), contextual memory decay (λ=0.80), and dynamic adaptive thresholding.
TIER 4
Target LLM & Mitigation
4-Tier state machine (ALLOW, WARN, RESTRICT, BLOCK) with δ=0.15 hysteresis preventing oscillating evasions.

2. How the Defense Thinks: Mathematical Signals & Decision Pipeline

Every conversational turn is analyzed in parallel across four distinct risk signals, accumulated in stateful memory, and evaluated against a dynamic adaptive threshold.

⚡ Turn Composite Risk (CRS) Instant Score
CRSt = 0.40·Ht + 0.30·Et + 0.20·St + 0.10·Bt
Weighted blend of immediate harm (40%), escalation speed (30%), semantic topic drift (20%), and bypass tricks (10%).
🧠 Contextual Memory (Ct) λ = 0.80 Decay
Ct = 0.80·Ct-1 + 0.20·CRSt   (t1/2 = 3.11 turns)
Retains past suspicious behavior across turns so attackers cannot slowly build up to dangerous payloads without triggering detection.
The 4 Component Signals (H, E, S, B)
🚨 H: Harmfulness 40% Weight
What it detects: Prohibited danger keywords & actionable exploit requests across 14 high-severity safety policies (CBRN, cyber exploits, malware, credentials).
Ht = 0.60·min(1, Countkw/3) + 0.40·Actionability
📈 E: Intent Escalation 30% Weight
What it detects: The speed at which questions become more dangerous across the last 5 turns via Ordinary Least Squares (OLS) linear regression slope.
Et = clip((SlopeOLS + 0.15) / 0.40, 0.0, 1.0)
🧬 S: Semantic Drift 20% Weight
What it detects: Topic migration away from the initial benign conversation anchor using FAISS dense embedding cosine similarity (384 dimensions).
St = 1.0 - max(CosineSimilarity(vt, Anchors))
🎭 B: Bypass Heuristics 10% Weight
What it detects: Known jailbreak tricks: persona roleplay (DAN), Base64/ROT13 encodings, character homoglyphs, and prompt instruction overrides.
Bt = ∑ wj · 𝕀(EvasionClassj)   [6 Patterns]
🎯 Dynamic Threshold (τt) & Bands Base τ₀ = 0.825
τt = clip(0.825 - 0.10·Dt - 0.15·Et - 0.05·Lt, 0.60, 0.85)
🟢 ALLOW (< 0.40)
Normal safe response
🟡 WARN (< 0.65)
Caution logged
🟠 RESTRICT (< τt)
Abstract educational only
🔴 BLOCK (≥ τt)
Request intercepted
🛡️ Hysteresis Anti-Oscillation (δ) Margin δ = 0.15
τrelease = τt - 0.15   (De-escalation requires Reff < τrelease)

Why it matters: Attackers often try "sawtooth evasion" by interleaving 1 dangerous question with 1 polite question to reset naive security filters.

The solution: Once elevated to RESTRICT or BLOCK, the defense latches. Downgrading requires at least 2 consecutive safe turns (< 0.35), completely shutting down flip-flop bypasses.
