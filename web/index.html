Full-Stack Multi-Turn Jailbreak Interception Framework

1. Four-Tier Full-Stack Architecture

The system is an integrated full-stack defense framework operating in real-time:

TIER 1
Web Research Testbench
Real-time telemetry, interactive Risk Journey stepper, Security Turn Cards, Trajectory Canvas, and 1-click audit reports.
TIER 2
REST API Gateway
Session state isolation, conversation history buffering, latency profiling, and dynamic preset scenario serving.
TIER 3
Stateful PRD Engine
Sub-25ms FAISS vector similarity, 4-signal fusion (H, E, S, B), contextual memory decay (λ=0.80), and dynamic adaptive thresholding.
TIER 4
Target LLM & Mitigation
4-Tier state machine (ALLOW, WARN, RESTRICT, BLOCK) with δ=0.15 hysteresis preventing oscillating evasions.

2. Core Mathematical Formulations & Active Parameters

⚡ CANONICAL RISK & STATEFUL MEMORY PRD Active (λ=0.80, T₀=0.75, δ=0.15)
CANONICAL RISK: CRSt = 0.40·Ht + 0.30·Et + 0.20·St + 0.10·Bt
CONTEXTUAL MEMORY: Ct = 0.80·Ct-1 + 0.20·CRSt   (Half-Life: t1/2 = 3.11 turns)
🚨 HARMFULNESS & ESCALATION (H, E) wH=0.40 · wE=0.30
Ht = min(1.0, Countkw / 3.0)×0.6 + Actionability×0.4 Et = clip((SlopeOLS + 0.15) / 0.40, 0.0, 1.0)
Ht: Instantaneous Harm — 14 high-severity regex safety domains (CBRN, automated exploit payloads, malware synthesis, credential theft).
Et: Intent Escalation Slope — Ordinary Least Squares (OLS) linear regression β over k=5 turn window; captures conceptual-to-operational transitions.
🧬 SEMANTIC & BYPASS (S, B) wS=0.20 · wB=0.10
St = 1.0 - maxi∈Anchors (vt · vi)   [FAISS FlatIP d=384] Bt = ∑j=1..6 wj · 𝕀(Heuristicj)   [6 Evasion Classes]
St: Cosine Drift from Safe Anchors — Dense embedding distance using all-MiniLM-L6-v2; flags semantic smuggling across turns.
Bt: Adversarial Bypass Heuristics — DAN/persona adoption, Base64/rot13 ciphers, character homoglyphs, instruction override prompts.
🎯 DYNAMIC ADAPTIVE THRESHOLD (τt) Base τ₀ = 0.825 · Bounds [0.60, 0.85]
τt = clip(0.825 - 0.10·Dt - 0.15·Et - 0.05·Lt, 0.60, 0.85) ALLOW (<0.40) · WARN (<0.65) · RESTRICT (<τt) · BLOCK (≥τt)
Dt: Anchor Drift = min(1.0, ||vt - v₁||₂ / √2) — penalizes departure from initial benign anchor.
Lt: Length Penalty = min(1.0, t / 10) — progressively tightens defense boundary against long-horizon attrition.
🛡️ HYSTERESIS & STATE MACHINE (δ) Release Margin δ = 0.15 · kcool ≥ 2
τrelease = τt - 0.15   (De-escalation requires Reff < τrelease) Persistent Cooldown: ≥ 2 consecutive turns below Reff < 0.35
State: 4-Tier State Machine Latch — Once in RESTRICT or BLOCK, states are latched to prevent single-turn flip-flop attacks.
δ: Anti-Oscillation Margin — Eliminates sawtooth evasion where attackers interleave malicious and benign prompts.
